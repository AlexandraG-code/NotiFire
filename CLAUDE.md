# notifierFrontend

Чат для отправки и получения текстовых сообщений через GREEN-API (тестовое задание, см. `src/task.txt`).
Пишем как кусок коммерческого проекта: аккуратно, расширяемо, без «одноразового» кода.

## Стек

React 19, TypeScript, Vite, antd, zustand, axios, react-router-dom. Не добавлять redux/RTK Query и другие менеджеры состояния.

## Архитектура

Feature-Sliced Design, алиасы `@app @pages @widgets @features @entities @shared`.
Слайс: `api/` (запросы), `model/` (стор, типы), `ui/` (компоненты), `index.ts` — публичный API.
Импорты между слайсами — только через `index.ts`; вышележащий слой импортирует нижележащий, не наоборот.

## Правила кода

- **Типы отдельно от логики.** Интерфейсы и типы — в `types.ts`, enum — в `enums.ts`, константы — в `constants.ts` рядом. Не смешивать с функциями и компонентами в одном файле.
- **Один файл — одна ответственность.** Не сваливать функции, классы и типы в один файл.
- **Никаких inline-типов** в сигнатурах (`options: { a?: X }`). Завести именованный `interface`/`type` и использовать его.
- **Никаких строковых литералов-значений** (имена методов API, маршруты, статусы, состояния, HTTP-методы). Только `enum` (разрешены, `erasableSyntaxOnly` выключен) или именованная константа. Исключение: тексты для пользователя.
- **Конфигурация — только через runtime-конфиг** `env-config.ts` в корне (`window._env_`, файл в .gitignore, шаблон — `env-config.ts.sample`). Новые параметры добавлять в sample и в тип `Window['_env_']` (`src/vite-global.d.ts`), читать напрямую через `window._env_`. `import.meta.env` и `.env` не использовать. Никаких захардкоженных URL и «магических» чисел — выносить в константы.
- **JSDoc** — на каждом компоненте, хуке, сервисе и функции с аргументами. Формат: описание в 1–2 строки, затем `@param {Тип} имя - описание` на каждый проп или аргумент (необязательные — `[имя]`), `@returns {Тип} описание` (у компонента `{JSX.Element}`) и `@throws`, если функция бросает. Для сторов — только описание. JSDoc не писать там, где он повторяет имя: enum, константы, простые типы.
- Секреты (`apiTokenInstance`) не логировать, не коммитить, не вставлять в код и тексты ошибок. Тексты сообщений рендерить как обычный текст, без `dangerouslySetInnerHTML`.
- Сервисы API принимают креды аргументом, глобального состояния не читают.
- Стиль: prettier (табы, без `;`, одинарные кавычки), `import type` для типов (`verbatimModuleSyntax`).
- **Цвета и размеры — только из темы.** Токены в `src/shared/theme` (`lightTokens.ts`, `darkTokens.ts`, тип `ThemeTokens`); в CSS — переменные `var(--color-*)`, в antd — токены через `getAntdTheme`. Хекс-цвета в компонентах и стилях не писать; новый цвет — сначала в оба набора токенов. Стили компонентов — CSS Modules (`*.module.css`).
- Файлы `.gitkeep` не заводить.

## Проверка перед коммитом

`yarn tsc -b && yarn lint`, затем `yarn format`. Один коммит на задачу.

## Комитет агентов

Защищённое (конфиги сборки, `.env*`, CI) правит только оркестратор. Чужой код проверяется `validator` перед записью в проект.
